# EPOCH Integrity Engine

The Integrity Engine is responsible for ensuring the reliability,
reproducibility, traceability, and validation of experiments in EPOCH.

## Core Responsibilities

- Dataset profiling
- Deterministic dataset splitting
- Dataset and experiment lineage
- Prediction validation
- Statistical validation
- Experiment budget enforcement
- Reproducibility verification
